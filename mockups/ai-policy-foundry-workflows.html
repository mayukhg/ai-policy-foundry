End-to-end happy path

Canonical flow for a versioned security manual (v1 → v2 delta).

  1. Upload or select cloud-security-manual-v2 (family with prior v1).
  2. Phase 1 deterministic filter builds a delta ChangePackage (added controls, changed sections).
  3. Configure AWS S3 · Production · CIS · generate.
  4. Phase 2 LLM agents draft YAML/Rego from the package only (no full-text stuffing).
  5. Edit / export · submit for review · approve · optional feedback.
  6. Later: threat alert → decide create new policy vs tweak existing (Wiz-aware).
